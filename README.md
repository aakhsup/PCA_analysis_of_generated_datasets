# PCA: Анализ главных компонент на сгенерированных 2D-датасетах

Лабораторная работа по исследованию метода главных компонент (Principal Component Analysis, PCA). Реализованы генерация синтетических датасетов, их визуализация в исходном пространстве и подробный анализ структуры данных с помощью PCA: Scree Plot, проекции на главные компоненты и анализ вклада исходных переменных.

---

## 📖 О проекте

Цель работы — продемонстрировать, как метод главных компонент выявляет скрытые структуры в данных, и наглядно показать его работу на синтетических датасетах разного размера.

### Что реализовано

| № | Задача | Инструменты |
|---|--------|-------------|
| 1 | Генерация датасетов размеров 4×4, 16×16, 256×256 | `numpy`, `pandas` |
| 2 | Визуализация исходных данных в пространстве X-Y | `matplotlib` |
| 3 | Стандартизация данных и применение PCA | `StandardScaler`, `PCA` |
| 4 | Scree Plot (доля объяснённой дисперсии и собственные значения) | `matplotlib`, метод Кайзера |
| 5 | Проекции объектов на первые `a` главных компонент (a = 4..8) | `matplotlib` |
| 6 | Проекции с отображением векторов старых переменных (loadings) | `PCA.components_`, `quiver` |
| 7 | Проекции на «дальние» компоненты (c..c+a, c ≥ 129) | `matplotlib` |
| 8 | Анализ малоинформативных компонент с векторами нагрузок | `matplotlib` |

---

## 📊 О данных

Датасеты генерируются искусственно по специальному правилу: в каждой строке `x` матрицы, начиная с колонки `y = x`, значения следующих `size/2` ячеек устанавливаются в «1». Оставшиеся ячейки равны «0». Это создаёт специфический диагональный паттерн, удобный для анализа структур методом PCA.

**Используемые размеры датасетов:**
- 4 × 4 — минимальный размер
- 16 × 16 — средний размер
- 256 × 256 — большой размер

**Признаки:** каждая колонка — отдельная переменная (X), каждая строка — отдельный объект (Y).

## 🎯 Ключевые результаты

### Scree Plot и метод Кайзера

Для каждого датасета построен график «каменистой осыпи» — доля объяснённой дисперсии для каждой главной компоненты, а также собственные значения с порогом Кайзера (λ = 1). На графиках видно, как резко убывает информативность после первых компонент — основная структура данных сосредоточена в младших компонентах.

| Датасет | Первые компоненты (≈ доля дисперсии) | Метод Кайзера |
|---------|:-------------------------------------:|:-------------:|
| **4 × 4** | ~0.63, ~0.32 | 2 компоненты |
| **16 × 16** | ~0.50, ~0.25, ~0.085 | 3 компоненты |
| **256 × 256** | Наибольший вклад — в первых компонентах | — |

### Проекции на главные компоненты

| Тип проекции | Что показывает |
|--------------|----------------|
| **Первые `a` компонент** | Чёткая структура — точки группируются по исходным строкам данных |
| **С векторами нагрузок** | Какие исходные признаки (колонки) определяют каждую компоненту |
| **«Дальние» компоненты (c ≥ 129)** | Практически не несут информации — данные выглядят как шум |

Это подтверждает выводы Scree Plot: информация о структуре данных сосредоточена в первых компонентах, а «дальние» компоненты содержат незначительные вариации.

## 🖼️ Визуализации

В ноутбуке построены:

- **Scatter-графики** исходных датасетов в пространстве X-Y.
- **Scree Plot** в двух вариантах: по доле дисперсии и по собственным значениям (с порогом Кайзера).
- **Матрица попарных проекций** на первые `a` главных компонент (без векторов и с векторами нагрузок).
- **Матрица попарных проекций** на «дальние» компоненты (c..c+a) для анализа малоинформативных направлений.
- **Векторы нагрузок** исходных переменных для каждой пары компонент (`quiver`).
